# Support

Centaur-Apex Core is a closed-source proprietary system. Support expectations:

| Need | Channel |
|------|---------|
| Operational or runbook questions | Internal ops channel (team) |
| Bug reports / feature requests | GitHub issues (internal) |
| **Security findings** | Private Security Advisory — *never* a public issue |
| Licensing / commercial use | Through the governance channel per `docs/GOVERNANCE.md` |
| Investment / advice | Nothing here is investment advice — see `docs/RISK-DISCLOSURE.md` |

There is no public community support. External parties should not expect
response SLAs; authorized contributors do have SLAs defined in `CONTRIBUTING.md`.
